Okay, so we have these macros

UCS_CLASS_INIT_FUNC
UCS_CLASS_CLEANUP_FUNC

They are used to make the initialze and cleanup functions for a class.
They make sure that initialize and cleanup functions follow a certain prototype such that UCX will now how to use it.
Uhh, kind of, no, it actually is a subclass of another class which UCX knows how to use.
Or wait yeah, UCX will call this UCS_CLASS_INIT_FUNC function, but then that function will call the super class constructor then do other setup.
UCS_CLASS_CALL_SUPER_INIT is used to call the super class's constructor, basically using container_of type of macros common in C and Linux.

UCS_CLASS_DEFINE actually defines what the class is, this will also be what is given as "self" in the init function for example, and other places.
UCX will pass in that object as a self parameter to each function (similar to classes in python actually).
